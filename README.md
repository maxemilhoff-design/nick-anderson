# Nick Anderson Knowledge Base

A Karpathy-style LLM wiki built from 35 of Nick Anderson's (Bull Runners) YouTube videos. This is a living knowledge base that compounds over time as more videos are ingested.

## Quick Start

**Read these first:**
- `wiki/index.md` — Master navigation. Find any page from here.
- `wiki/hot.md` — Quick context: content pillars, voice markers, current focus.

## How to Use for Scripting

1. **Find hooks:** `wiki/hooks/hook-index.md` — every hook organized by type
2. **Find CTA copy:** `wiki/ctas/cta-index.md` — which offer to use when, with verbatim language
3. **Research a topic:** `wiki/concepts/[topic].md` — what Nick has said about it, how he frames it
4. **Check if Nick covered something:** `wiki/sources/` — scan summaries of all 35 videos
5. **Understand Nick's structure:** `wiki/patterns/content-formula.md` — his video formula in one page
